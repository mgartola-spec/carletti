# carletti

Landing page del estudio contable Carletti & Artola.

## Publicación

El sitio se publica automáticamente en GitHub Pages mediante el workflow
`.github/workflows/deploy-pages.yml` cada vez que se actualiza la rama `main`.

URL esperada: `https://mgartola-spec.github.io/carletti/`

Para probarlo localmente:

```bash
npm install
npm start
```
